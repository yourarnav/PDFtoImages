Local & Privacy-First

Stop uploading sensitive files
to random web converters.

Every day, millions of legal agreements, financial statements, and confidential PDFs get uploaded to ad-riddled online conversion websites. PDF to Images runs 100% on your Mac’s local CPU. Not a single byte ever leaves your machine.

Engineered with Precision

Built like a genuine Mac app.

⚡

Ultra-Lean Native Binary

Hand-tuned Objective-C Cocoa compiled directly with Clang -O3. Under 270 KB universal binary (~130 KB per arch) with instant 0ms launch and clean termination.

🛡️

Header Magic Verification

Inspects the first 1024 bytes for %PDF- magic bytes before processing, safely rejecting non-PDF files disguised with a .pdf extension.

📁

APFS Atomic Safety

Uses atomic file locking and handles case-insensitive macOS file systems so folder creations never overwrite your existing files or trigger race conditions.

🎯

Drag to Window or Dock

Drop PDFs into the window or directly onto the application icon in your macOS Dock. Multi-file queues batch process in parallel automatically.

📐

Retina DPI Precision

Choose from 150 DPI for web and sharing, 300 DPI for standard print, or 600 DPI for razor-sharp vector rendering and typography reproduction.

🧹

Instant Failure Cleanup

If a conversion is cancelled or encounters a damaged PDF, partial temporary folders are atomically purged immediately. Your Desktop stays pristine.

Distribution

Get it with Homebrew or DMG.

The easiest way to install. Homebrew automatically manages Poppler dependencies for you:

zsh
$ brew install --cask yourarnav/tap/pdftoimages
